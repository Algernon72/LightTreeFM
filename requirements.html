LightTreeFM · System requirements

Requirements

LightTreeFM is designed for classic Amiga computers, accelerated systems and compatible emulators. It supports native Amiga graphics, RTG displays and PiStorm configurations.

Minimum configuration

  • Operating system: AmigaOS 2.05 or later.
  • Processor: Motorola 68000.
  • Memory: LightTreeFM can run with just 2 MB of Chip RAM and no Fast RAM.
  • Graphics: Native Amiga graphics.

On a Chip RAM-only system, available memory limits the operations you can perform and the external tools you can run alongside LightTreeFM. Even a modest amount of Fast RAM makes everyday use more comfortable and practical.

Recommended configuration

  • Operating system: AmigaOS 2.05 or later.
  • Processor: Motorola 68020 or faster, including PiStorm configurations.
  • Memory: Some Fast RAM is strongly recommended. The amount of free Chip RAM needed depends on the screen configuration and other running applications.
  • Graphics: Native Amiga graphics or an RTG display.

Additional Fast RAM provides more room for larger directories, archive operations and multitasking. LightTreeFM also supports 68030, 68040 and 68060 accelerators.

External tools

Archive operations require the appropriate external utilities, such as LHA, LZX, ZIP/UNZIP, ARC and DMS. These utilities have their own processor and memory requirements.

One executable for classic and accelerated Amigas

LightTreeFM uses a single 68000-compatible executable. It adapts its behaviour to the available operating system, libraries, screen and hardware, without requiring separate builds for different processor configurations.
